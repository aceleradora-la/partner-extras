# partner-extras

Módulos extra de Odoo para clientes y proveedores.

Compatible con Odoo **Community** y **Enterprise**. Cada versión de Odoo tiene
su propia rama: `17.0`, `18.0` y `19.0`.

## Módulos

| Módulo | Descripción |
|--------|-------------|
| [`partner_fantasy_name`](partner_fantasy_name/) | Nombre de Fantasía en clientes/proveedores, buscable en pedidos de venta, facturas y disponible en las tablas dinámicas de los reportes de ventas y facturación. |

## Instalación

```bash
git clone -b 18.0 https://github.com/aceleradora-la/partner-extras.git
```

(reemplazar `18.0` por la rama correspondiente a su versión de Odoo)

Agregar la carpeta al `addons_path` de Odoo, actualizar la lista de
aplicaciones e instalar el módulo deseado.
